# Adaptive Interview AI

An AI-powered adaptive interview platform built for the **ABTalks Hackathon – The Interview Agent** problem statement.

The platform creates personalized interviews based on candidate profiles, curriculum, previous answers, and interview performance.

## 🚀 Features

- Candidate management
- Personalized interview planning
- Adaptive question generation
- AI-powered answer evaluation
- Interview state management
- Conversation memory
- Performance analytics
- AI assistant
- Final interview feedback and recommendations
- React frontend
- TypeScript/Express backend
- Frontend–backend API integration

## 🛠️ Tech Stack

### Frontend

### Backend
